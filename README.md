# Pet Store storefront on Spring Boot

A migration of the `petstore` storefront from the Java Pet Store Demo 1.3.1_02
(J2EE 1.3: JSP, EJB 2.0, JMS, Ant) to Spring Boot on Java 21.

> **Status: migration in progress.** Build and run instructions, the approach
> taken and the key decisions are documented here once the migration is
> complete.
